헷갈리기 쉬운 문법

'주어'와 '목적어'는 단어 종류(품사)가 아니라 문장 속 역할입니다. 주어 표현에는 대명사·호칭을, 목적어 연습에는 자주 쓰는 명사를 넣었습니다. 동사도 실제로는 무수히 많지만 첫 주에는 핵심 동사 5개를 반복합니다.

DAY 1

생활 베트남어 · 오늘의 상황

매일 30분 추천 학습

30분은 권장 학습 시간입니다. 자동으로 시간을 재지 않습니다. 말하기 완료는 직접 따라 말한 뒤 체크해 주세요. 단어 발음은 기기 기본 베트남어 TTS로 재생되며 실제 원어민 발음과 다를 수 있습니다.

오늘의 실생활 회화 5문장

단어 분해 + 듣고 따라 말하기

① 🔊 듣기 → ② 소리 내어 3회 따라 말하기 → ③ 문장 안의 단어 뜻 확인 → ④ 아래에서 베트남어로 직접 쓰기

✍️ 베트남어 문장 직접 쓰기

한국어 뜻을 보고 베트남어 철자와 성조 기호까지 입력하세요. 기존 정식 시험(한국어 뜻 쓰기)과는 별도 연습입니다. 오답 문장은 다음 날 복습합니다.

🔊 직접 써서 베트남어로 듣기

한국어 문장을 쓰면 베트남어로 바꿔 읽어줍니다. 베트남어를 쓰면 번역 없이 그대로 발음해 줍니다. 한글로 적은 베트남어 발음도 일부 기본 표현은 인식합니다.

문장을 입력하고 변환 버튼을 누르세요.

한국어는 먼저 앱의 생활 회화 예문에서 찾아 번역합니다. 없는 문장은 데스크톱 Chrome 내장 번역(지원되는 경우)을 우선 시도하고, 필요하면 외부 번역 서비스(MyMemory)에 입력한 한국어 문장만 전송해 번역합니다. 번역에는 인터넷이 필요할 수 있고, 결과가 부정확하거나 번역 서비스가 제한될 수 있습니다. 개인 정보나 비밀번호를 입력하지 마세요. 입력 문장은 학습 기록이나 Firebase에 저장하지 않습니다.

일주일 학습표

매일 주어 5개 + 동사 5개 + 목적어 연습 5개를 반복합니다. 명사 5개는 매일 바뀌며, 틀린 명사가 있다면 새 단어 대신 다시 등장합니다.

아래 일정은 기본 계획입니다. 오답이 많으면 신규 단어가 뒤로 밀릴 수 있습니다. 7일 이후 남은 새 단어와 복습은 계속 학습할 수 있습니다.

시험·오답 기록

시험의 실제 문항과 응답, 채점 결과를 저장합니다. 단어와 문장별 오답 횟수도 표시합니다.

Firebase 연동

웹앱은 계정 없이도 작동합니다(브라우저 로컬 저장). Firebase를 연결하고 Google 계정으로 로그인하면 같은 계정의 PC·갤럭시 간 시험 기록을 동기화할 수 있습니다.

별도 Firebase 프로젝트를 생성하고 Authentication의 Google 로그인, Cloud Firestore, 이 프로젝트에 포함된 보안 규칙을 활성화해야 합니다. Firebase 설정만 입력했다고 자동으로 클라우드 저장되지는 않습니다.
